# P3 beats (draft, for Mo to approve or edit)

General education only. No figures beyond the five years, which come from facts.json once confirmed.

1. OAS, 1952: A basic pension for older Canadians. Today it is the base layer many retirement incomes start from.
2. RRSP, 1957: A tax break for people with no workplace pension. Today it is one common way to build the private layer.
3. CPP, 1966: A pension earned through work and contributions. Today it adds a layer that follows a person's work history.
4. TFSA, 2009: Savings that grow without tax on the growth. Today it is a flexible place to save beside the RRSP.
5. FHSA, 2023: Savings aimed at a first home. Today it is the newest account, built for one goal.

# The ages that matter (P5c): spec

Three retirement rules laid out square by square in the shared P5 colour scale, from confirmed facts only (Mo approved the
sketch, 2026-11-11): every CPP start month from the earliest to the latest age, shaded by the change against the standard
start; every OAS start month, shaded by the deferral increase; the RRIF minimum factor at every age in the regulations' table.
A picker and a readout in words for each, tables for screen readers. The RRIF readout applies the factor to an example fund
of $100,000 (Mo: "I like the example... if it makes it easier to understand"), labelled as an illustration, not anyone's
amount. No rate, age or factor in code (a test checks); a missing fact stops the build. General rules only: no amounts
beyond the example, no projection, nothing about which start is better.
